# PRE-C01 — Retorno

[Aluno](student.md).

Leitura: Kim coordena, Lee é cliente, Jo escreve o nome de Lee. Chá dentro pela manhã. Ligar para Kim em 0508; mensagem escrita para Lee em 0806. Não trocar destinatários por estarem na mesma linha.

Roteiro de escuta: “My name is Ana. Water, please. Inside, please.” Dados: Ana, água, dentro. A consulta escrita é leitura e deve ser registrada assim.

Tarefa: Rui coordena, Ana trabalha, escrever Kim; manhã beber água; noite dormir; mensagem para Kim 0407. Exemplo de blocos: “Rui, manager. Ana, worker. Write Kim. Morning: drink water. Night: sleep. Text Kim: zero, four, zero, seven.”

Retomada: Ana coordena, Rui é cliente; Kim lê nome de Rui; água dentro pela manhã; text Ana 0902; ready antes, finished depois. A inversão posterior muda quem executa/recebe, não os demais dados.

Avaliação: Eva coordena, Lee trabalha, Jo é cliente; Lee escreve Jo. Chá fora de manhã, tempo ensolarado. Call Eva 0603; text Jo 0109. Modelo de mediação: “Na sexta, Lee deve escrever o nome do cliente Jo. O chá é fora de manhã. Para ligar a Eva use 0603; para mandar mensagem a Jo, 0109.” Não há hora exata. A repetição oral só pode ser avaliada se realizada e compreendida.

Recuperação: se trocou pessoas, sublinhe rótulos; se trocou canal, compare call/text e refaça com dois nomes novos; se perdeu zero, registre números em caixas de quatro dígitos. Faça outra tentativa em encontro posterior sem copiar este modelo.
