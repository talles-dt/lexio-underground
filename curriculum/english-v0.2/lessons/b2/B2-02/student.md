# B2-02 — Discutir alternativas passadas sem confundir hipótese e culpa

Estado: material autoral B2 em revisão; sem pilotagem ou aprovação CEFR. Pré-requisitos: [B2-01](../../b2/B2-01/student.md) · [B1-04](../../b1/B1-04/student.md) · [B1-08](../../b1/B1-08/student.md). Se um pré-requisito impedir a tarefa, volte ao apoio correspondente; não é necessário decorar todas as frases.

## O que fazer ao final

Distinguir fatos, alternativas contrafactuais e consequências atuais; formular arrependimentos e propostas de reparação sem inventar causas.

## Palavras e expressões para esta situação

backup = cópia de segurança; venue = local; regret = arrependimento; outcome = resultado; restore = restaurar; take responsibility = assumir responsabilidade; misleading = enganoso no efeito, sem provar intenção; outage = interrupção. Could have = poderia ter; would have = teria no cenário hipotético.

## Syntaxis — como construir o sentido

If + had + particípio, would have + particípio imagina passado diferente: If we had downloaded the file, we would have had a local copy. Não descreve fato ocorrido. Could/might have deixam possibilidade: We might have finished earlier. Condicional mista pode ligar passado e presente: If we had saved the file, we would have it now. Também um estado atual mais geral pode enquadrar passado: If I were more confident with the equipment, I would have offered to help yesterday. A frase apresenta a interpretação do falante, não prova causal. Wish + passado expressa desejo contrário ao presente: I wish we had a backup now. Wish + past perfect trata passado: I wish we had saved it. If only enfatiza desejo/arrependimento; não substitui investigação de fatos.

## Leia para agir

### Relato de um encontro de cinema — ficção

Our discussion group planned to show a short film on Saturday. We had permission to screen it, but the organiser kept the only available copy in an online folder. Nobody downloaded it before the meeting. At seven, the internet connection at the venue stopped working. We could not open the folder, so we discussed photographs from the film instead. The film screening did not happen that evening.  
Looking back, I wish we had downloaded the permitted copy beforehand. If we had done so, we would have had a local file available. That does not prove the whole evening would have gone perfectly: we had not tested the sound system either. A local file would have removed one obstacle, not every possible obstacle.  
The folder is still inaccessible today, and we have no local copy. If we had saved the file on Friday, we would have it now. I wish we had a clear backup procedure. We can create one before the next meeting, but we should not describe that future procedure as something that already existed.

### Resposta de outro participante

I agree that a local copy would have helped, provided it was covered by the permission we had. However, I disagree with the message saying that the organiser deliberately ruined the event. The account tells us that the copy was online and the connection failed. It gives us no evidence of deliberate sabotage.  
I also regret not offering technical help. If I were more confident with the equipment, I would have offered to test it before the meeting. That is my reflection on my own confidence; it is not proof that my help would have prevented the outage. If only we had checked the sound system as well. We might have discovered another issue in advance, or we might have found it working normally. We cannot know which from the current record.  
For the next event, I suggest a short checklist with named responsibilities: confirm permission, obtain the appropriate file, test playback and agree an alternative activity. We should test that plan rather than promise that no problem can ever happen again.

## Prática orientada

1. Complete: If we ___ the file, we would have had a copy. (download)
2. A frase anterior afirma que baixaram o arquivo?
3. Complete consequência atual: If we had saved it, we ___ it now. (have)
4. Expresse arrependimento de não testar: I wish we ___.
5. Expresse desejo de ter procedimento agora: I wish we ___.
6. Explique diferença entre would have had a copy e might have finished earlier.
7. Complete: If I ___ more confident, I would have offered to help yesterday. (be)
8. Corrija: If we had tested the sound, we definitely would have prevented the internet outage.
9. Formule If only sobre ausência de teste passado.

Confira as respostas somente depois de tentar no [retorno comentado](feedback.md). Uma resposta alternativa pode ser válida se preservar o sentido e a forma-alvo.

## Shadow — trocar informação

A defende que baixar arquivo teria garantido evento perfeito; B usa fontes para distinguir uma barreira removida de sucesso total. Depois A reformula sem acusação. B apresenta desejo atual e arrependimento passado. Produzam checklist para próximo encontro, atribuindo responsáveis fictícios, sem marcar tarefas como realizadas.

O destinatário deve devolver os dados que entendeu. Troquem papéis. Sem parceiro, faça um ensaio gravado e deixe interação como não observada.

## Phonos — fazer-se entender

Contraste had CHECKED / would HAVE it NOW; destaque marcadores temporais. O colega classifica passado ou presente a partir de frases completas. Aceite had em forma plena antes de trabalhar contrações ambíguas como we’d.

## Nova situação — produzir e mediar

Nova ficção: oficina de desenho tinha materiais para dez, mas doze chegaram. Lista de inscrição com doze estava disponível desde quinta; não foi consultada. Sábado duas pessoas compartilharam lápis. Hoje ainda faltam dois conjuntos; não há evidência de intenção de excluir. A sala comportava doze e estava pronta. Escreva análise de 150–190 palavras: fato, alternativa passada, consequência presente, arrependimento e reparação. Não invente que consultar lista garantiria estoque na loja.

Faça a primeira tentativa sem copiar o modelo. Guarde sua produção e a resposta do destinatário. Use os [critérios](feedback.md) para localizar um acerto e uma necessidade de recuperação.

## Pulse — retorno em outro encontro

Em encontro posterior: convite tinha endereço antigo; ninguém conferiu; três pessoas foram ao lugar errado ontem. Hoje o convite continua sem correção. Formule um arrependimento e uma condicional mista; proponha ação presente.

Confira o retorno apenas depois da tentativa. No Palácio, registre duas expressões com o contexto em que foram úteis. Evite registrar só uma tradução sem situação.

## Percurso autônomo

1. Leia o objetivo e o apoio; procure os dados nas fontes e anote dúvidas.
2. Ouça, responda e faça a prática antes de consultar o retorno. Compare primeira tentativa e correção.
3. Faça a troca com parceiro ou ensaio identificado; produza a situação nova e explique os dados ao destinatário.
4. No encontro indicado, recupere o conteúdo antes de reler. Anote tempo real, apoios e próxima necessidade.

Não há prazo universal ou carga validada. Se a leitura das instruções for o obstáculo, esclareça-a em português sem fornecer a resposta em inglês.
