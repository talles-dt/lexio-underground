# LEX-C1-03 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-c1-bcd17f-a"></a>
- **Item 1:** Plano viável, equipe não consultada. Declare ressalva.

<a id="lx-c1-596811-a"></a>
- **Item 2:** Ambos querem qualidade, discordam de custo. Reformule ponto comum.

<a id="lx-c1-cc7fa5-a"></a>
- **Item 3:** Consulta começou, respostas ainda não analisadas. Descreva pendência.

<a id="lx-c1-e7881d-a"></a>
- **Item 4:** Recebeu mensagem, fatos ainda não verificados. Redija reconhecimento limitado.

<a id="lx-c1-701a55-a"></a>
- **Item 5:** Dois horários rejeitados, proposta nova possível. Descreva sem encerramento definitivo.


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
