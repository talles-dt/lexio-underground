# LEX-C1-07 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-c1-e8c560-a"></a>
- **Item 1:** Fonte diz exportação funciona, importação não testada. Explique limite em linguagem comum.

<a id="lx-c1-c5c283-a"></a>
- **Item 2:** Plano reduz papel e aumenta necessidade de ajuda presencial, não prevista. Relate.

<a id="lx-c1-4ed5b7-a"></a>
- **Item 3:** Compare duas propostas com diferentes ganhos sem escolher universalmente.

<a id="lx-c1-23fc32-a"></a>
- **Item 4:** Equipe usa único turno para revisão, adia gravação. Explique em linguagem comum.

<a id="lx-c1-11c8e6-a"></a>
- **Item 5:** Estudo só com adultos experientes, aplicação pretendida a iniciantes. Explique limite.


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
