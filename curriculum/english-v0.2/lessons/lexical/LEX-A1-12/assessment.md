# LEX-A1-12 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-a1-c9db4d-a"></a>
- **Item 1:** Cartão de Jo: zangado com atraso. Fale como Jo com apoio delay.

<a id="lx-a1-2d401e-a"></a>
- **Item 2:** Reunião é amanhã; personagem se declara preocupado. Escreva mensagem curta.

<a id="lx-a1-5956ef-a"></a>
- **Item 3:** Personagem vai ao cinema sábado e está animado. Use modelo.

<a id="lx-a1-a900a2-a"></a>
- **Item 4:** Personagem se sente entediado, colega gosta da atividade. Diga só sentimento do personagem.

<a id="lx-a1-0726ee-a"></a>
- **Item 5:** Escreva impressão sobre nova colega com apoio seems = parece.

<a id="lx-a1-aab155-a"></a>
- **Item 6:** Cartão traz autodescrição de Lee: shy. Relate com Lee says… = Lee diz.


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
