# LEX-A2-19 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-a2-9e87e9-a"></a>
- **Item 1:** Plano mudou de sábado para domingo. Escreva nova rotina com laundry.

<a id="lx-a2-402184-a"></a>
- **Item 2:** Jo cooks; Lee washes plates. Diga tarefa de Lee com washing-up.

<a id="lx-a2-b2ed52-a"></a>
- **Item 3:** Segunda Jo limpa, terça Lee, quarta Jo. Explique padrão com take turns.

<a id="lx-a2-f70d67-a"></a>
- **Item 4:** Cartão Jo waters plants while Lee is away. Resuma responsabilidade com look after.

<a id="lx-a2-3615f1-a"></a>
- **Item 5:** Prazo 18:00; envio 17:50. Diga que foi entregue dentro do prazo com on time.

<a id="lx-a2-c9cdf2-a"></a>
- **Item 6:** Pessoa chega pontualmente mas diz in a hurry. Há contradição necessária?


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
