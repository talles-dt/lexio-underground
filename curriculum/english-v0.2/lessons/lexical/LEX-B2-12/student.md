# LEX-B2-12 — Planejar uma refeição e descrever preferências

Após [B2-06](../../b2/B2-06/student.md). Material autoral; não revisado independentemente nem pilotado.

## Percurso

Primeiro estude sentidos e exemplos; depois faça a prática antes de consultar respostas. Faça a situação em dupla ou registre ensaio individual. No início do encontro seguinte, antes de reler, abra [retomada](review.md). Depois da correção e em uma sessão separada, faça a [avaliação](assessment.md), sem consultar previamente suas respostas. Datas e duração são registradas, não presumidas.

## Sentidos, formas e prática

<a id="lx-b2-e33eef-i"></a>
### cut down on

**Sentido:** reduzir consumo ou frequência. **Padrão:** cut down on something. **Exemplo:** We want to cut down on disposable packaging.

reduzir não é necessariamente eliminar

<a id="lx-b2-e33eef-p"></a>
**Prática:** Diga reduzir quantidade de compras desnecessárias de comida.

<a id="lx-b2-8baf86-i"></a>
### run out of

**Sentido:** ficar sem um recurso. **Padrão:** run out of something. **Exemplo:** We’ve run out of rice.

distinguir acabar de estar com pouco

<a id="lx-b2-8baf86-p"></a>
**Prática:** Diga que não resta arroz.

<a id="lx-b2-e94a30-i"></a>
### leftovers

**Sentido:** comida que sobrou de uma refeição. **Padrão:** leftovers from a meal. **Exemplo:** There are leftovers from dinner.

plural neste uso; termo não garante segurança para consumo

<a id="lx-b2-e94a30-p"></a>
**Prática:** Nomeie porções de comida que sobraram de uma refeição.

<a id="lx-b2-7cecb4-i"></a>
### use up

**Sentido:** usar até esgotar. **Padrão:** use something up. **Exemplo:** We used up the flour.

use it up com pronome

<a id="lx-b2-7cecb4-p"></a>
**Prática:** Diga usar todo o papel disponível.

<a id="lx-b2-96e3fc-i"></a>
### bland

**Sentido:** de sabor pouco marcante. **Padrão:** find food bland. **Exemplo:** I find this soup bland.

opinião de sabor não é avaliação nutricional

<a id="lx-b2-96e3fc-p"></a>
**Prática:** Comida descrita como de sabor pouco marcante: adjetivo?

<a id="lx-b2-57d4b3-i"></a>
### filling

**Sentido:** que dá sensação de saciedade. **Padrão:** a filling meal. **Exemplo:** It was a small but filling meal.

adjetivo neste uso; percepção contextual

<a id="lx-b2-57d4b3-p"></a>
**Prática:** Refeição dá sensação de saciedade. Descreva.

<a id="uso"></a>
## Usar para realizar uma tarefa

A e B planejam jantar fictício. Arroz acabou, há farinha suficiente para duas porções e legumes para duas. A sugere usar toda farinha para evitar compra adicional; B quer reduzir compras desnecessárias, não eliminar alimentação. Há sobras no frigorífico com data desconhecida: descrevam sem concluir que podem ser consumidas. Após refeição fictícia de legumes e massa, A a considera pouco marcante de sabor, B a considera saciante. Negociem próxima compra respeitando preferências.

**Critério:** o destinatário precisa recuperar os dados finais indicados no [retorno](feedback.md). Marque cada palavra como usada com apoio, usada sem modelo, reconhecida somente ou não observada. Sem parceiro, há ensaio, não interação observada.

## Phonos, Pulse, Palácio, Shadow e Syntaxis

Contraste run OUT OF rice com still HAVE flour. O parceiro faz lista do que acabou e do que permanece. Pratique use IT up com pronome.

No Pulse, use a retomada com dados diferentes. No Palácio, guarde uma expressão com situação própria; no Shadow, troque papéis e confirme o que o ouvinte entendeu. Consulte as microaulas Syntaxis da unidade de fundamentos se uma forma bloquear o sentido.
