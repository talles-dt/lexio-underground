# LEX-B2-12 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-b2-e33eef-a"></a>
- **Item 1:** Grupo quer diminuir embalagens descartáveis, sem meta numérica. Proponha ação.

<a id="lx-b2-8baf86-a"></a>
- **Item 2:** Ainda há dois ovos, mas leite acabou. Descreva com precisão.

<a id="lx-b2-e94a30-a"></a>
- **Item 3:** Personagem guardou sobras, mas data é desconhecida. Descreva sem recomendar consumo.

<a id="lx-b2-7cecb4-a"></a>
- **Item 4:** Receita fictícia usou toda farinha, ainda há açúcar. Relate.

<a id="lx-b2-96e3fc-a"></a>
- **Item 5:** Você acha sopa pouco temperada; formule opinião pessoal, sem regra universal.

<a id="lx-b2-57d4b3-a"></a>
- **Item 6:** Refeição pequena satisfez personagem. Relate percepção sem alegação de saúde.


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
