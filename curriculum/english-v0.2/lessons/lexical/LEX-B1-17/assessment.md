# LEX-B1-17 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-b1-e94a30-a"></a>
- **Item 1:** Relato: some dinner remained; it became lunch. Resuma com leftovers sem inventar armazenamento.

<a id="lx-b1-2b84db-a"></a>
- **Item 2:** Uma pessoa diz homemade, logo healthier. O que a palavra sozinha permite afirmar?

<a id="lx-b1-73d6a8-a"></a>
- **Item 3:** Cardápio não dá peso. Cliente pede small portion. Você pode afirmar 100 gramas?

<a id="lx-b1-356e38-a"></a>
- **Item 4:** Relato says mild flavour; colega escreve tasteless, sem sabor. Preserve o relato.

<a id="lx-b1-496d67-a"></a>
- **Item 5:** Prato é servido frio e tem pimenta forte. Descreva picância sem afirmar temperatura alta.

<a id="lx-b1-f0b6fd-a"></a>
- **Item 6:** Atendente diz unable to leave out onions. Registre se pedido foi aceito.


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
