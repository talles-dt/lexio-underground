# LEX-A1-18 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-a1-0927e8-a"></a>
- **Item 1:** Você ouviu uma palavra mas precisa ouvi-la de novo; formule pedido.

<a id="lx-a1-d68f6d-a"></a>
- **Item 2:** A colega soletrou o termo mas você ainda não sabe o sentido. Peça a informação que falta.

<a id="lx-a1-723a7a-a"></a>
- **Item 3:** Recepção: nome falado é Kim. Faça pergunta para registrar a grafia.

<a id="lx-a1-0b476c-a"></a>
- **Item 4:** Ouviu ticket ten credits e anotou dez; confira com pergunta.

<a id="lx-a1-319096-a"></a>
- **Item 5:** Mensagem at ten — I mean at twelve. Qual hora registrar?

<a id="lx-a1-3363f8-a"></a>
- **Item 6:** Você precisa conferir depois um número. Peça ao interlocutor que o escreva.


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
