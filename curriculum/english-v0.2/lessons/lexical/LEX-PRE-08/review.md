# LEX-PRE-08 — retomada no encontro seguinte

[Ensino](student.md) · [Retorno](feedback.md). Faça antes de reler o ensino; anote o apoio. Se precisar, consulte e marque tentativa com consulta. Não confundir correção imediata com retomada posterior.

<a id="lx-pre-a1-d3e77a-r"></a>
- **Item 1:** Escreva o algarismo de zero.

<a id="lx-pre-a1-7491da-r"></a>
- **Item 2:** Ligue one ao cartão 1 ou 2.

<a id="lx-pre-a1-251b12-r"></a>
- **Item 3:** Escreva o algarismo de two.

<a id="lx-pre-a1-9993a7-r"></a>
- **Item 4:** Leia 3 usando three.

<a id="lx-pre-a1-aa5441-r"></a>
- **Item 5:** Escreva o algarismo de four.

<a id="lx-pre-a1-6d24ce-r"></a>
- **Item 6:** Ligue five a 4 ou 5.
