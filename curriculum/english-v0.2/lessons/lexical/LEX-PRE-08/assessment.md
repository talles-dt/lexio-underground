# LEX-PRE-08 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-pre-a1-d3e77a-a"></a>
- **Item 1:** Leia o código 0–2: zero, two. Qual é o primeiro algarismo?

<a id="lx-pre-a1-7491da-a"></a>
- **Item 2:** Há uma caneta no desenho ou objeto mostrado. Complete ___ pen.

<a id="lx-pre-a1-251b12-a"></a>
- **Item 3:** Pedido “Two pens, please”. Quantas canetas entregar?

<a id="lx-pre-a1-9993a7-a"></a>
- **Item 4:** Código escrito 3–1. Leia por algarismos com apoio three, one.

<a id="lx-pre-a1-aa5441-a"></a>
- **Item 5:** Sala escrita Room 4. Diga a sala com modelo Room ___.

<a id="lx-pre-a1-6d24ce-a"></a>
- **Item 6:** Código 5–0. Leia com apoio five, zero.


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
