# LEX-A1-21 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-a1-9f7326-a"></a>
- **Item 1:** Agenda 1 June: leia com apoio the...of June.

<a id="lx-a1-5a6bfc-a"></a>
- **Item 2:** Data 2 August: leia com the...of August.

<a id="lx-a1-dd3e1a-a"></a>
- **Item 3:** Data 3 September: diga com the...of September.

<a id="lx-a1-89bae7-a"></a>
- **Item 4:** Agenda 21 October: leia a data com apoio.

<a id="lx-a1-ebb8df-a"></a>
- **Item 5:** Mensagem June thirtieth; colega marca June thirteen. Qual data correta?

<a id="lx-a1-c41cbe-a"></a>
- **Item 6:** Formulário diz 31 April; calendário fornecido mostra April termina em 30. Confirme se é possível registrar essa data.


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
