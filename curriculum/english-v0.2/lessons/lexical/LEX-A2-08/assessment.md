# LEX-A2-08 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-a2-b482ce-a"></a>
- **Item 1:** Pergunte onde deixar bagagem, com apoio Where can I leave…?

<a id="lx-a2-4ed6fa-a"></a>
- **Item 2:** Reserva confirmada, chegada amanhã. Diga que ainda não fez registro de chegada.

<a id="lx-a2-47837f-a"></a>
- **Item 3:** Você pretende sair às dez, limite onze. Diga seu plano.

<a id="lx-a2-2eecd1-a"></a>
- **Item 4:** Reserva diz single room, café não informado. Confirme tipo e pergunte sobre café com apoio Is breakfast included?

<a id="lx-a2-5fadb8-a"></a>
- **Item 5:** Pergunte onde fica recepção com Where is…?


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
