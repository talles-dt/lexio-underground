# LEX-A2-09 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-a2-cb9cd8-a"></a>
- **Item 1:** Personagem ontem tinha dor de cabeça, hoje não. Relate com apoio.

<a id="lx-a2-0562f8-a"></a>
- **Item 2:** Ficha pede motivo do contato. Escreva que tem dor de garganta desde ontem com apoio since yesterday.

<a id="lx-a2-8fd643-a"></a>
- **Item 3:** No cartão, personagem sente enjoo agora. Use feel sick e tradução para esclarecer.

<a id="lx-a2-25a867-a"></a>
- **Item 4:** Ainda há dor de garganta, mas menor incômodo. Relate sem afirmar cura.

<a id="lx-a2-b82c4c-a"></a>
- **Item 5:** Personagem diz que ontem estava melhor que hoje. Relate estado atual com worse.


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
