# LEX-B1-21 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-b1-7105f9-a"></a>
- **Item 1:** Duas marcas diferentes, mesma composição; pode concluir qual dura mais só pela marca?

<a id="lx-b1-2dc0f8-a"></a>
- **Item 2:** Peça second-hand, condição não descrita. Pode afirmar worn out?

<a id="lx-b1-eaa09e-a"></a>
- **Item 3:** Etiqueta used once, foto sem desgaste visível; worn out é sustentado só por used?

<a id="lx-b1-35a197-a"></a>
- **Item 4:** Review says lasted three years; advert says durable. Relate duas fontes sem garantia universal.

<a id="lx-b1-e26d6a-a"></a>
- **Item 5:** Casaco barato mas reparo caro; explique por que talvez não seja bargain.

<a id="lx-b1-2e2662-a"></a>
- **Item 6:** Loja respondeu return refused. Pode registrar refund received?


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
