# LEX-A2-04 — retomada no encontro seguinte

[Ensino](student.md) · [Retorno](feedback.md). Faça antes de reler o ensino; anote o apoio. Se precisar, consulte e marque tentativa com consulta. Não confundir correção imediata com retomada posterior.

<a id="lx-a2-258cda-r"></a>
- **Item 1:** No próximo encontro, diga que não recebeu o anexo.

<a id="lx-a2-2c55ce-r"></a>
- **Item 2:** Em outro dia, peça resposta ao e-mail até sexta. Apoio: by Friday = até sexta.

<a id="lx-a2-502430-r"></a>
- **Item 3:** Na próxima sessão, relate dificuldade de entrada sem fornecer senha.

<a id="lx-a2-c85d9d-r"></a>
- **Item 4:** Em outro dia, diga que precisa mudar uma senha fictícia sem escrevê-la.

<a id="lx-a2-9ab384-r"></a>
- **Item 5:** Na próxima sessão, substitua the room por it em We need to set up the room.

<a id="lx-a2-455bc9-r"></a>
- **Item 6:** Em outro dia, use pronome em Please fill in this form.

<a id="lx-a2-1dc5e4-r"></a>
- **Item 7:** Na próxima sessão, peça desligar a luz usando the light e depois it.

<a id="lx-a2-2698e7-r"></a>
- **Item 8:** Em outro dia, marque formulário enviado, sala ainda não confirmada usando already.

<a id="lx-a2-114802-r"></a>
- **Item 9:** Na próxima sessão, pergunte se a pessoa já respondeu ao e-mail usando yet.
