# LEX-A2-04 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-a2-258cda-a"></a>
- **Item 1:** Mensagem com arquivo de imagem anexado, sem áudio. Informe o que o attachment contém.

<a id="lx-a2-2c55ce-a"></a>
- **Item 2:** Você recebeu uma resposta sem confirmação de horário. Reply significa que o horário está confirmado?

<a id="lx-a2-502430-a"></a>
- **Item 3:** Cartão fictício: entrada na conta funcionou, envio de arquivo falhou. Diga o que funcionou com log in.

<a id="lx-a2-c85d9d-a"></a>
- **Item 4:** Suporte pede descrição do erro, não senha. Explique em inglês que não é necessário enviar a senha, com apoio don’t need to.

<a id="lx-a2-9ab384-a"></a>
- **Item 5:** Sala precisa de mesas e cadeiras antes do encontro. Peça ajuda para prepará-la usando set up.

<a id="lx-a2-455bc9-a"></a>
- **Item 6:** Formulário vazio; tarefa solicita completar dados fictícios. Dê a instrução em inglês com fill in.

<a id="lx-a2-1dc5e4-a"></a>
- **Item 7:** Microfone deve ser desligado depois da gravação. Dê instrução com pronome.

<a id="lx-a2-2698e7-a"></a>
- **Item 8:** A confirmação chegou, pagamento pendente. Escreva só a etapa concluída usando already.

<a id="lx-a2-114802-a"></a>
- **Item 9:** Solicitação enviada, nenhuma resposta. Escreva o estado com yet.


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
