# LEX-A2-04 — Atualizar mensagem e procedimento digital

Após [A2-06](../../a2/A2-06/student.md). Material autoral; não revisado independentemente nem pilotado.

## Percurso

Primeiro estude sentidos e exemplos; depois faça a prática antes de consultar respostas. Faça a situação em dupla ou registre ensaio individual. No início do encontro seguinte, antes de reler, abra [retomada](review.md). Depois da correção e em uma sessão separada, faça a [avaliação](assessment.md), sem consultar previamente suas respostas. Datas e duração são registradas, não presumidas.

## Sentidos, formas e prática

<a id="lx-a2-258cda-i"></a>
### attachment

**Sentido:** anexo de mensagem. **Padrão:** attach/an attachment. **Exemplo:** The details are in the attachment.

não afirmar que foi enviado sem conferir

<a id="lx-a2-258cda-p"></a>
**Prática:** O e-mail diz See attachment. Isso garante que o anexo chegou?

<a id="lx-a2-2c55ce-i"></a>
### reply

**Sentido:** responder mensagem. **Padrão:** reply to + mensagem. **Exemplo:** Please reply to this email.

não reply me no padrão-alvo

<a id="lx-a2-2c55ce-p"></a>
**Prática:** Corrija: Please reply me.

<a id="lx-a2-502430-i"></a>
### log in

**Sentido:** entrar em conta. **Padrão:** log in to + serviço. **Exemplo:** I can’t log in to the site.

login pode funcionar como nome

<a id="lx-a2-502430-p"></a>
**Prática:** Log in to a site significa entrar na conta ou apagar a conta?

<a id="lx-a2-c85d9d-i"></a>
### password

**Sentido:** senha. **Padrão:** change a password. **Exemplo:** I need to change my password.

usar exemplo fictício, não solicitar senha real

<a id="lx-a2-c85d9d-p"></a>
**Prática:** Password corresponde a senha ou nome de usuário necessariamente?

<a id="lx-a2-9ab384-i"></a>
### set up

**Sentido:** preparar ou montar. **Padrão:** set something up. **Exemplo:** We need to set up the room.

set it up com pronome no meio

<a id="lx-a2-9ab384-p"></a>
**Prática:** Set up the room neste contexto significa preparar sala ou sair dela?

<a id="lx-a2-455bc9-i"></a>
### fill in

**Sentido:** preencher. **Padrão:** fill in a form. **Exemplo:** Please fill in this form.

fill out é alternativa frequente

<a id="lx-a2-455bc9-p"></a>
**Prática:** Fill in a form significa preencher ou apenas ler?

<a id="lx-a2-1dc5e4-i"></a>
### turn off

**Sentido:** desligar. **Padrão:** turn something off. **Exemplo:** Turn the lamp off when you leave.

turn it off, não turn off it

<a id="lx-a2-1dc5e4-p"></a>
**Prática:** Corrija: Turn off it.

<a id="lx-a2-2698e7-i"></a>
### already

**Sentido:** já, conclusão anterior. **Padrão:** already + particípio. **Exemplo:** I’ve already sent the invitation.

não implica outra tarefa concluída

<a id="lx-a2-2698e7-p"></a>
**Prática:** I’ve already sent it prova envio ou recebimento pelo destinatário?

<a id="lx-a2-114802-i"></a>
### yet

**Sentido:** ainda/já em expectativa. **Padrão:** not yet / have you…yet. **Exemplo:** We haven’t booked it yet.

não significa nunca

<a id="lx-a2-114802-p"></a>
**Prática:** I haven’t booked it yet significa nunca reservou nada ou reserva atual ainda pendente?

<a id="uso"></a>
## Usar para realizar uma tarefa

Simulação em papel: A consegue log in com cartão fictício, já preencheu formulário e enviou mensagem, mas esqueceu attachment. B responde pedindo anexo e informa que sala ainda não foi set up. A completa envio, confirma o que already foi feito e o que not yet. Após gravar uma saudação fictícia, pede turn it off para o microfone. Ninguém escreve ou envia senha real; só menciona password numa frase sobre não compartilhar.

**Critério:** o destinatário precisa recuperar os dados finais indicados no [retorno](feedback.md). Marque cada palavra como usada com apoio, usada sem modelo, reconhecida somente ou não observada. Sem parceiro, há ensaio, não interação observada.

## Phonos, Pulse, Palácio, Shadow e Syntaxis

Ouça have/haven’t com apoio e registre estados por tarefa. Se só ler, marcar leitura; não fingir escuta.

No Pulse, use a retomada com dados diferentes. No Palácio, guarde uma expressão com situação própria; no Shadow, troque papéis e confirme o que o ouvinte entendeu. Consulte as microaulas Syntaxis da unidade de fundamentos se uma forma bloquear o sentido.
