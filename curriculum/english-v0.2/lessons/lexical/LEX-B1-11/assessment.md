# LEX-B1-11 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-b1-705a2b-a"></a>
- **Item 1:** Produto 20 mais taxa 4. Relate custo total fictício.

<a id="lx-b1-e2e673-a"></a>
- **Item 2:** Mensagem pede confirmar se há cobrança extra. Faça pergunta.

<a id="lx-b1-2e15ef-a"></a>
- **Item 3:** Você gostou de aula, colega não. Dê avaliação pessoal com worth.

<a id="lx-b1-313ac4-a"></a>
- **Item 4:** Ana recebe bolsa de Lee temporariamente. Relate com borrow.

<a id="lx-b1-06d280-a"></a>
- **Item 5:** Lee fornece bolsa a Ana temporariamente. Relate sem trocar direção.


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
