# LEX-PRE-17 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-pre-a1-4e0a76-a"></a>
- **Item 1:** Personagem diz I’m happy. Explique em português.

<a id="lx-pre-a1-1cbaa9-a"></a>
- **Item 2:** Fale como personagem que declara tristeza usando modelo I’m…

<a id="lx-pre-a1-6594f3-a"></a>
- **Item 3:** Personagem está com fome e pede pão. Use os blocos I’m hungry e Bread, please.

<a id="lx-pre-a1-baa5f3-a"></a>
- **Item 4:** Personagem está com sede e pede água. Use blocos conhecidos.

<a id="lx-pre-a1-1521fa-a"></a>
- **Item 5:** Personagem diz I’m hot; indique sensação em português.

<a id="lx-pre-a1-36cb4d-a"></a>
- **Item 6:** Fale como personagem com frio, usando I’m cold.


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
