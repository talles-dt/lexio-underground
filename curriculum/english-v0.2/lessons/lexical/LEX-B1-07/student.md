# LEX-B1-07 — Planejar recursos e reduzir desperdício

Após [B1-08](../../b1/B1-08/student.md). Material autoral; não revisado independentemente nem pilotado.

## Percurso

Primeiro estude sentidos e exemplos; depois faça a prática antes de consultar respostas. Faça a situação em dupla ou registre ensaio individual. No início do encontro seguinte, antes de reler, abra [retomada](review.md). Depois da correção e em uma sessão separada, faça a [avaliação](assessment.md), sem consultar previamente suas respostas. Datas e duração são registradas, não presumidas.

## Sentidos, formas e prática

<a id="lx-b1-650ad1-i"></a>
### waste

**Sentido:** desperdício ou resíduo. **Padrão:** food waste. **Exemplo:** We want to reduce food waste.

definir qual sentido no texto

<a id="lx-b1-650ad1-p"></a>
**Prática:** Nomeie comida descartada sem uso neste cenário.

<a id="lx-b1-6fece1-i"></a>
### reuse

**Sentido:** reutilizar. **Padrão:** reuse + objeto. **Exemplo:** We reuse the glass jars.

diferente de reciclar material

<a id="lx-b1-6fece1-p"></a>
**Prática:** Diga usar caixas novamente. Use reuse.

<a id="lx-b1-cefcc6-i"></a>
### afford

**Sentido:** ter recursos para. **Padrão:** afford to + verbo. **Exemplo:** I can’t afford to travel now.

não juízo sobre responsabilidade pessoal

<a id="lx-b1-cefcc6-p"></a>
**Prática:** Diga não ter recursos para pagar o ingresso agora.

<a id="lx-b1-16bf79-i"></a>
### save up

**Sentido:** economizar para objetivo. **Padrão:** save up for + item. **Exemplo:** I’m saving up for a course.

não necessariamente investir

<a id="lx-b1-16bf79-p"></a>
**Prática:** Diga economizar para um curso.

<a id="uso"></a>
## Usar para realizar uma tarefa

Grupo tem 60 créditos, meta de 100 para oficina. Caixas novas custam 25; há caixas reutilizáveis adequadas sem custo. A quer comprar agora, B propõe reaproveitar e guardar recursos. Escolham com base no objetivo; 60 permite comprar caixas, mas reduz reserva para oficina. Não confundir poder pagar uma compra com alcançar a meta.

**Critério:** o destinatário precisa recuperar os dados finais indicados no [retorno](feedback.md). Marque cada palavra como usada com apoio, usada sem modelo, reconhecida somente ou não observada. Sem parceiro, há ensaio, não interação observada.

## Phonos, Pulse, Palácio, Shadow e Syntaxis

Confira FORTY / SIXTY-FIVE em frases com a hipótese correspondente.

No Pulse, use a retomada com dados diferentes. No Palácio, guarde uma expressão com situação própria; no Shadow, troque papéis e confirme o que o ouvinte entendeu. Consulte as microaulas Syntaxis da unidade de fundamentos se uma forma bloquear o sentido.
