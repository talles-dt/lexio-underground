# LEX-B1-25 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-b1-d205b3-a"></a>
- **Item 1:** Você prefere museu mas sem pesquisa. Marque opinião.

<a id="lx-b1-16481c-a"></a>
- **Item 2:** Opção é mais perto mas mais cara. Cite vantagem sem apagar custo.

<a id="lx-b1-359e67-a"></a>
- **Item 3:** Opção barata sem acesso por elevador; critério exige acesso. Nomeie drawback sem recomendar ignorá-lo.

<a id="lx-b1-6e1d57-a"></a>
- **Item 4:** Horário incerto, não declare viagem confirmada; recomende conferir.

<a id="lx-b1-1a969f-a"></a>
- **Item 5:** Fonte often but not always. Reformule com tend to.

<a id="lx-b1-923035-a"></a>
- **Item 6:** Uma opção atende critério principal e tem custo maior. Conclua com ressalva.


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
