# LEX-B1-02 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-b1-40f59a-a"></a>
- **Item 1:** Seu turno muda de manhã para tarde só sexta. Avise.

<a id="lx-b1-bf66f6-a"></a>
- **Item 2:** Escreva que se candidatou ontem e espera resposta.

<a id="lx-b1-695ce9-a"></a>
- **Item 3:** Pergunte quais qualificações são necessárias, sem inventar credenciais próprias.

<a id="lx-b1-5f20e0-a"></a>
- **Item 4:** Peça confirmação do prazo de um formulário sem presumir que foi prorrogado.

<a id="lx-b1-e703e2-a"></a>
- **Item 5:** Distinga pausar por dez minutos de deixar de tentar.

<a id="lx-b1-be76f0-a"></a>
- **Item 6:** Ainda não há solução para transporte. Proponha tentar resolvê-la juntos.


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
