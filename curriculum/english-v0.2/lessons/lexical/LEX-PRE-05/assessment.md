# LEX-PRE-05 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-pre-a1-ee36f6-a"></a>
- **Item 1:** Cartão: três livros. Peça os três com book e número.

<a id="lx-pre-a1-204177-a"></a>
- **Item 2:** Cartão: Lee tem uma caneta; Jo tem um telefone. Diga qual objeto Lee tem com o nome em inglês.

<a id="lx-pre-a1-c96d05-a"></a>
- **Item 3:** Você esqueceu uma bolsa. Escolha a etiqueta adequada entre bag, table e phone.

<a id="lx-pre-a1-6c81b2-a"></a>
- **Item 4:** Cartão de devolução: “a phone”. Deve devolver telefone, bolsa ou livro?

<a id="lx-pre-a1-ef9783-a"></a>
- **Item 5:** O convite pede “Bring a chair” (traga uma cadeira). Escolha cadeira ou mesa para levar.

<a id="lx-pre-a1-e4b3ca-a"></a>
- **Item 6:** Uma pessoa aponta uma mesa e pergunta “Table?”. Confirme; depois dê o nome em inglês.


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
