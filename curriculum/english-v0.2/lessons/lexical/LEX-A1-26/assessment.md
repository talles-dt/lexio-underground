# LEX-A1-26 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-a1-2f1e5a-a"></a>
- **Item 1:** Mapa library then post office next door. Localize correio.

<a id="lx-a1-09863f-a"></a>
- **Item 2:** Mapa police station opposite park. Onde fica em relação ao parque?

<a id="lx-a1-794e53-a"></a>
- **Item 3:** Placa Mon–Fri 09:00–17:00. Domingo está incluído?

<a id="lx-a1-d7f0c9-a"></a>
- **Item 4:** Placa closed today; pessoa quer entrar hoje. Há atendimento confirmado?

<a id="lx-a1-08374e-a"></a>
- **Item 5:** Campo Name vazio; deve colocar nome fictício ou preço?

<a id="lx-a1-b1f313-a"></a>
- **Item 6:** Mensagem appointment requested, no time confirmed. Há hora marcada?
