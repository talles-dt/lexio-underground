# LEX-A2-10 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-a2-252686-a"></a>
- **Item 1:** Oficina aceitou pedido, trabalho amanhã. Relate sem dizer que terminou.

<a id="lx-a2-25a336-a"></a>
- **Item 2:** Você sabe que aparelho está quebrado, mas não causa. Escreva duas frases com apoio.

<a id="lx-a2-421630-a"></a>
- **Item 3:** Camisa nova de mesmo modelo, outra cor desejada. Faça pedido sem dizer que já foi aceito.

<a id="lx-a2-b73ccb-a"></a>
- **Item 4:** Entrega prevista sexta ainda não ocorreu. Relate com apoio expected.

<a id="lx-a2-9b39f4-a"></a>
- **Item 5:** Você pediu cancelamento, aguarda retorno. Relate com apoio confirmation.


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
