# LEX-B1-08 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-b1-4a83de-a"></a>
- **Item 1:** Colega cumpriu todos os três prazos descritos. Faça avaliação limitada à experiência.

<a id="lx-b1-3b8f51-a"></a>
- **Item 2:** Viagem foi cancelada; personagem sente decepção, causa desconhecida. Relate.

<a id="lx-b1-dcee11-a"></a>
- **Item 3:** Você enviou horário errado. Faça pedido de desculpas com apologize/apologise.

<a id="lx-b1-ee0fd6-a"></a>
- **Item 4:** Confia na colega, mas precisa confirmar envio. Separe ideias.

<a id="lx-b1-3ed9ad-a"></a>
- **Item 5:** Após curso, proponha manter contato sem promessa de frequência.


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
