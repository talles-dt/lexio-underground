# LEX-A2-23 — Explicar um procedimento digital simulado

Após [A2-06](../../a2/A2-06/student.md). Material autoral; não revisado independentemente nem pilotado.

## Percurso

Primeiro estude sentidos e exemplos; depois faça a prática antes de consultar respostas. Faça a situação em dupla ou registre ensaio individual. No início do encontro seguinte, antes de reler, abra [retomada](review.md). Depois da correção e em uma sessão separada, faça a [avaliação](assessment.md), sem consultar previamente suas respostas. Datas e duração são registradas, não presumidas.

## Sentidos, formas e prática

<a id="lx-a2-9f577b-i"></a>
### plug in

**Sentido:** conectar aparelho à alimentação no cenário. **Padrão:** plug it in. **Exemplo:** Plug it in before switching it on.

Simulação em desenho de aparelho inofensivo; não instruir reparo elétrico. Pronome entre plug/in.

<a id="lx-a2-9f577b-p"></a>
**Prática:** Escolha plug it in/plug in it.

<a id="lx-a2-7f78ed-i"></a>
### switch on

**Sentido:** ligar aparelho. **Padrão:** switch it on. **Exemplo:** Switch the tablet on.

Turn on é alternativa; não confundir com log in.

<a id="lx-a2-7f78ed-p"></a>
**Prática:** Switch on tablet significa ligar ou entrar em conta?

<a id="lx-a2-846332-i"></a>
### press

**Sentido:** pressionar botão. **Padrão:** press + botão. **Exemplo:** Press Save.

Press é pressionar neste uso, não imprensa.

<a id="lx-a2-846332-p"></a>
**Prática:** Press Save: qual botão?

<a id="lx-a2-b0a73b-i"></a>
### download

**Sentido:** transferir arquivo de serviço para dispositivo. **Padrão:** download a file. **Exemplo:** Download the worksheet.

Cenário com arquivo autorizado fictício; não confundir enviar para serviço/upload.

<a id="lx-a2-b0a73b-p"></a>
**Prática:** Download traz arquivo ao dispositivo ou envia do dispositivo?

<a id="lx-a2-86d966-i"></a>
### save

**Sentido:** salvar arquivo ou alterações. **Padrão:** save the file. **Exemplo:** Save the file before closing it.

Save aqui não é economizar dinheiro; fechamento não garante salvamento.

<a id="lx-a2-86d966-p"></a>
**Prática:** Close garante save automaticamente neste cenário?

<a id="lx-a2-1c3066-i"></a>
### restart

**Sentido:** reiniciar. **Padrão:** restart the device. **Exemplo:** Restart the device after saving.

Reiniciar não é restaurar configurações de fábrica; seguir roteiro fictício apenas.

<a id="lx-a2-1c3066-p"></a>
**Prática:** Restart equivale a apagar tudo/factory reset?

<a id="uso"></a>
## Usar para realizar uma tarefa

Use desenho de tablet, sem conta real. Roteiro: plug in; switch on; press Download to receive worksheet; complete name field with fictitious name; press Save; restart after saving. B recebeu versão errada restart before save. A explica ordem e corrige B. Transferência: novo desenho já ligado e arquivo já baixado; diga apenas etapas ainda necessárias, sem repetir preparação concluída. Autônomo: numere cartões, escreva instruções e compare estado inicial.

**Critério:** o destinatário precisa recuperar os dados finais indicados no [retorno](feedback.md). Marque cada palavra como usada com apoio, usada sem modelo, reconhecida somente ou não observada. Sem parceiro, há ensaio, não interação observada.

## Phonos, Pulse, Palácio, Shadow e Syntaxis

Agrupe verbos e objeto: plug IT in, switch IT on, press SAVE. Ouvir ordem é diferente de só conhecer palavras.

No Pulse, use a retomada com dados diferentes. No Palácio, guarde uma expressão com situação própria; no Shadow, troque papéis e confirme o que o ouvinte entendeu. Consulte as microaulas Syntaxis da unidade de fundamentos se uma forma bloquear o sentido.
