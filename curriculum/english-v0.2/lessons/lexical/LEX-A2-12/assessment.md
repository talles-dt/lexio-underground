# LEX-A2-12 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-a2-a07e96-a"></a>
- **Item 1:** Personagem ontem estava nervoso, hoje sente calma. Relate mudança com apoio calm.

<a id="lx-a2-51fb5f-a"></a>
- **Item 2:** Mensagem inesperada mudou horário. Relate surpresa sem avaliar mudança como boa.

<a id="lx-a2-ee95e9-a"></a>
- **Item 3:** Personagem mora só e não se sente solitário. Expresse contraste com apoio lives alone.

<a id="lx-a2-b56f62-a"></a>
- **Item 4:** Personagem diz upset, esclarece sad not angry. Preserve distinção.

<a id="lx-a2-c28825-a"></a>
- **Item 5:** Depois de receber horário confirmado, personagem se declara calmo. Relate com now.

<a id="lx-a2-d6eb05-a"></a>
- **Item 6:** Personagem concluiu primeira apresentação e sente orgulho. Relate.


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
