# LEX-C1-06 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-c1-e57b1a-a"></a>
- **Item 1:** Pessoa revisará convenções de escrita conhecidas. Relate.

<a id="lx-c1-71e475-a"></a>
- **Item 2:** Duas opções equivalentes em custo e acesso, só data difere. Explique escolha.

<a id="lx-c1-99a79d-a"></a>
- **Item 3:** Redija equivalente neutro para destinatário que não conhece expressão.

<a id="lx-c1-fa7866-a"></a>
- **Item 4:** Pedido de relatório amplo em uma hora. Negocie redução.

<a id="lx-c1-025335-a"></a>
- **Item 5:** Colega sempre ajudou; desta vez não confirmou. Faça pergunta em vez de presumir.


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
