# LEX-A2-06 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-a2-7e54f4-a"></a>
- **Item 1:** Texto escrito por Eva sobre personagem Kim. Quem é character e quem é writer (autora)?

<a id="lx-a2-e996ac-a"></a>
- **Item 2:** História termina sem revelar escolha do personagem. Descreva ending como aberto, com apoio open.

<a id="lx-a2-0cc44f-a"></a>
- **Item 3:** Escolha para quem sente interesse: I’m interested / interesting in the story.

<a id="lx-a2-49d7a3-a"></a>
- **Item 4:** Pessoa gostou do filme, colega o achou boring. Isso prova que todos sentiram tédio?


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
