# LEX-B1-16 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-b1-1ebe90-a"></a>
- **Item 1:** Evento sexta passa à próxima segunda. Escreva aviso claro.

<a id="lx-b1-2eb00d-a"></a>
- **Item 2:** Reunião dia 18 passa para dia 16 do mesmo mês. Escreva ambas as datas.

<a id="lx-b1-34b8a8-a"></a>
- **Item 3:** Ônibus está 15 minutos atrasado, chegada exata desconhecida. Faça aviso.

<a id="lx-b1-79309f-a"></a>
- **Item 4:** Entrega foi adiada. Podemos preparar as etiquetas enquanto esperamos. Escreva ligação.

<a id="lx-b1-930b69-a"></a>
- **Item 5:** Depois de duas revisões, o grupo concordou. Redija com eventually.

<a id="lx-b1-fe898b-a"></a>
- **Item 6:** Relato diz duas horas extras, nada sobre pagamento. Faça síntese fiel.


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
