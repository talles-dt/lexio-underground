# LEX-B1-23 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-b1-b108d8-a"></a>
- **Item 1:** Título New route; texto proposed route. Pode anunciar rota já operando?

<a id="lx-b1-456031-a"></a>
- **Item 2:** Post sem autor/data. Registre lacuna de source, sem inventar origem.

<a id="lx-b1-3a90f2-a"></a>
- **Item 3:** Leu só headline. Pode dizer que leu entire article?

<a id="lx-b1-1e85fd-a"></a>
- **Item 4:** Fonte relata atraso; você não verificou independentemente. Formule com report.

<a id="lx-b1-96abf8-a"></a>
- **Item 5:** Título omite que dado é antigo. Explique problema sem atribuir intenção.

<a id="lx-b1-ee823c-a"></a>
- **Item 6:** Artigo não apresenta evidência. Resuma sem dizer que jamais existe evidência.


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
