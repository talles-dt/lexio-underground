# LEX-A2-20 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-a2-efafc6-a"></a>
- **Item 1:** Aluno vai rever as notas antes da prova. Escreva plano usando revise.

<a id="lx-a2-d1c70a-a"></a>
- **Item 2:** Colega decorou resposta mas não consegue explicar. Pode dizer memorised it sem afirmar understood it?

<a id="lx-a2-f8807b-a"></a>
- **Item 3:** Aluno agora entende instruções antes incompreendidas. Escreva relato com progress limitado a isso.

<a id="lx-a2-234895-a"></a>
- **Item 4:** Fonte diz Friday, aluno copiou Thursday. Localize erro com mistake.

<a id="lx-a2-693ebd-a"></a>
- **Item 5:** Instrução says choose one; aluno marca três. Descreva diferença sem julgar pessoa.

<a id="lx-a2-db1ff4-a"></a>
- **Item 6:** Há livro, áudio e dicionário; só áudio sem transcrição está indisponível. Escolha recurso utilizável para consultar grafia.


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
