# LEX-A2-20 — Escolher recursos e rever o estudo

Após [A2-07](../../a2/A2-07/student.md). Material autoral; não revisado independentemente nem pilotado.

## Percurso

Primeiro estude sentidos e exemplos; depois faça a prática antes de consultar respostas. Faça a situação em dupla ou registre ensaio individual. No início do encontro seguinte, antes de reler, abra [retomada](review.md). Depois da correção e em uma sessão separada, faça a [avaliação](assessment.md), sem consultar previamente suas respostas. Datas e duração são registradas, não presumidas.

## Sentidos, formas e prática

<a id="lx-a2-efafc6-i"></a>
### revise

**Sentido:** rever conteúdo para estudo. **Padrão:** revise for a test. **Exemplo:** I revise for the test on Friday.

No uso britânico é estudar revisão; review/study for são alternativas americanas. Não significa só corrigir texto.

<a id="lx-a2-efafc6-p"></a>
**Prática:** Revise for a test: revisar conteúdo ou apenas marcar data?

<a id="lx-a2-d1c70a-i"></a>
### memorise

**Sentido:** memorizar. **Padrão:** memorise + informação. **Exemplo:** I memorised the phone number.

Memorize é grafia americana; memorização não prova uso em situação nova.

<a id="lx-a2-d1c70a-p"></a>
**Prática:** Memorise um número significa necessariamente compreender todo texto?

<a id="lx-a2-f8807b-i"></a>
### make progress

**Sentido:** avançar na aprendizagem. **Padrão:** make progress in + área. **Exemplo:** I am making progress in English.

Progress é incontável: não a progress. Evidência de avanço deve ser descrita separadamente.

<a id="lx-a2-f8807b-p"></a>
**Prática:** Escolha make progress/make a progress.

<a id="lx-a2-234895-i"></a>
### mistake

**Sentido:** erro de execução ou entendimento. **Padrão:** make a mistake. **Exemplo:** I made a mistake in the date.

Make a mistake, não do a mistake neste padrão.

<a id="lx-a2-234895-p"></a>
**Prática:** Errou a data: make ou do a mistake?

<a id="lx-a2-693ebd-i"></a>
### instructions

**Sentido:** instruções para realizar tarefa. **Padrão:** follow the instructions. **Exemplo:** Read the instructions before starting.

Aqui plural; pode haver uma instruction específica. Ler não garante cumprir.

<a id="lx-a2-693ebd-p"></a>
**Prática:** Instructions dizem write two sentences. Quantas frases?

<a id="lx-a2-db1ff4-i"></a>
### resource

**Sentido:** recurso usado para aprender. **Padrão:** a learning resource. **Exemplo:** This dictionary is a useful resource.

Resource pode ser livro, áudio ou ferramenta; disponibilidade não garante adequação.

<a id="lx-a2-db1ff4-p"></a>
**Prática:** Dicionário usado para estudar pode ser resource?

<a id="uso"></a>
## Usar para realizar uma tarefa

Relato de Lee: I memorised ten answers. In a new task, I understood two instructions that I did not understand last week. I made a mistake in the date. Resources: dictionary available, notes available, audio unavailable today. A ajuda Lee a preparar revisão para uma tarefa nova de leitura: escolha recurso, identifique evidência limitada de avanço e proponha ação para o erro. B explica o plano em 60–90 palavras. Troquem com Kim: memorised five phrases; understood a new message; mistake in room number; resources notes and audio available, dictionary unavailable. Autônomo: compare memorizar e usar em situação nova, citando dado de cada cartão.

**Critério:** o destinatário precisa recuperar os dados finais indicados no [retorno](feedback.md). Marque cada palavra como usada com apoio, usada sem modelo, reconhecida somente ou não observada. Sem parceiro, há ensaio, não interação observada.

## Phonos, Pulse, Palácio, Shadow e Syntaxis

Diferencie instrução e resposta ao ler cartões; áudio indisponível não deve ser registrado como escuta realizada.

No Pulse, use a retomada com dados diferentes. No Palácio, guarde uma expressão com situação própria; no Shadow, troque papéis e confirme o que o ouvinte entendeu. Consulte as microaulas Syntaxis da unidade de fundamentos se uma forma bloquear o sentido.
