# LEX-B2-01 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-b2-80384c-a"></a>
- **Item 1:** Dado mostra presença estável, manchete diz que dobrou. Avalie com back up.

<a id="lx-b2-78e19a-a"></a>
- **Item 2:** Dois serviços têm preços distintos, sem detalhamento. Peça explicação da diferença.

<a id="lx-b2-a2e283-a"></a>
- **Item 3:** Três avaliações citam demora, mas não explicam causa. Relate indício com limite.

<a id="lx-b2-10b80e-a"></a>
- **Item 4:** Pesquisa de satisfação exclui desistentes. Descreva possível viés sem acusar intenção.

<a id="lx-b2-7c2121-a"></a>
- **Item 5:** Só 15 pessoas responderam dentre 50 convidadas. Descreva grupo analisado.

<a id="lx-b2-d79e41-a"></a>
- **Item 6:** Projeto quer reduzir espera; só registrou reuniões. Explique falta de evidência de resultado.

<a id="lx-b2-057514-a"></a>
- **Item 7:** De 60% para 45%, mesma definição e base comparável. Relate queda em pontos percentuais.


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
