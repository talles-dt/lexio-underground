# LEX-PRE-26 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-pre-a1-9adc30-a"></a>
- **Item 1:** Jo is a worker here. Sabemos que Jo é professor?

<a id="lx-pre-a1-87f9ed-a"></a>
- **Item 2:** Worker: Jo; Manager: Lee. Quem procurar se instrução diz manager?

<a id="lx-pre-a1-e1a733-a"></a>
- **Item 3:** Cartão Ana customer, Jo worker. Quem é cliente?

<a id="lx-pre-a1-8e77b9-a"></a>
- **Item 4:** Cartão Task: read names. Apoio read names = ler nomes. Qual tarefa?

<a id="lx-pre-a1-1b2285-a"></a>
- **Item 5:** Pessoa diz not ready. Começar imediatamente foi confirmado?

<a id="lx-pre-a1-5b0ec7-a"></a>
- **Item 6:** Cartão Task: write name. Nome escrito; pessoa diz I am finished. Qual status?


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
