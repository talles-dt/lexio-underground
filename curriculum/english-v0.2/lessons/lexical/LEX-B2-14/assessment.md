# LEX-B2-14 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-b2-69f3fc-a"></a>
- **Item 1:** Equipe relata frustração, continua procurando alternativa. Relate ambas as coisas.

<a id="lx-b2-c120d0-a"></a>
- **Item 2:** Personagem consegue fazer tarefa, mas não volume simultâneo. Formule pedido delimitado.

<a id="lx-b2-87c847-a"></a>
- **Item 3:** Pessoa evita gravar porque relata inibição, não falta comprovada de habilidade. Separe.

<a id="lx-b2-4e750c-a"></a>
- **Item 4:** Gestor entende dificuldade, mas não pode mudar prazo. Relate.

<a id="lx-b2-32abf1-a"></a>
- **Item 5:** Pessoa consultou preferências e ofereceu alternativa. Descreva ato.

<a id="lx-b2-545f51-a"></a>
- **Item 6:** Dois leitores discordam sobre mensagem. Atribua avaliação a um deles.


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
