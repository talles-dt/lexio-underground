# LEX-C1-02 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-c1-cf1db7-a"></a>
- **Item 1:** Um mês concorda com previsão anual. Delimite suporte.

<a id="lx-c1-3dd657-a"></a>
- **Item 2:** Proposta economiza tempo, mas aumenta custo do usuário. Formule contraponto.

<a id="lx-c1-af9533-a"></a>
- **Item 3:** Conclusão usa orçamento estável, mas verba incerta. Questione base.

<a id="lx-c1-69abd0-a"></a>
- **Item 4:** Orçamento aprovado, execução depende de espaço. Separe.

<a id="lx-c1-f9301d-a"></a>
- **Item 5:** Opção A acessível, mais cara; orçamento comporta. Justifique preferência situada.

<a id="lx-c1-75f496-a"></a>
- **Item 6:** Amostra exclui grupo importante. Relate efeito sobre generalização.


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
