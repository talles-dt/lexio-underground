# LEX-A2-03 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-a2-5a420a-a"></a>
- **Item 1:** Personagem diz tired após trabalho. Reconte o que disse sem atribuir doença.

<a id="lx-a2-ff5f20-a"></a>
- **Item 2:** Compromisso11h; novo acordo14h. Escreva confirmação com appointment.

<a id="lx-a2-9a2c7e-a"></a>
- **Item 3:** Cartão: Jo pede descanso entre atividades. Reescreva o pedido com rest sem recomendar duração médica.

<a id="lx-a2-f069f4-a"></a>
- **Item 4:** Regra: break between activities. A pausa foi permitida durante qualquer frase?

<a id="lx-a2-dca340-a"></a>
- **Item 5:** Regra permite água, proíbe comida. Escreva uma frase com allowed.

<a id="lx-a2-c221ae-a"></a>
- **Item 6:** Regra: presença obrigatória, câmera optional. Podemos exigir câmera ligada como condição dada?


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
