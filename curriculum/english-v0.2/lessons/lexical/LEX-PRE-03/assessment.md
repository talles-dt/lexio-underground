# LEX-PRE-03 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-pre-a1-9d8e7d-a"></a>
- **Item 1:** Você quer chá. Faça o pedido com a expressão de cortesia estudada.

<a id="lx-pre-a1-12d8ce-a"></a>
- **Item 2:** O atendente entrega o café correto. Agradeça usando a expressão estudada.

<a id="lx-pre-a1-c804dc-a"></a>
- **Item 3:** Ouça um código dito uma vez; solicite que seja repetido com a expressão estudada.

<a id="lx-pre-a1-891329-a"></a>
- **Item 4:** A recepção dita rapidamente 804. Peça um ritmo mais lento, não um número diferente.

<a id="lx-pre-a1-39b752-a"></a>
- **Item 5:** Você está diante de duas fichas e não entende a instrução. Use help num pedido curto.

<a id="lx-pre-a1-efafe6-a"></a>
- **Item 6:** Seu cartão indica tea. O atendente confirma tea. Confirme o produto.

<a id="lx-pre-a1-af26d0-a"></a>
- **Item 7:** Você quer tea; o atendente confirma coffee. Corrija sem mudar seu pedido.


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
