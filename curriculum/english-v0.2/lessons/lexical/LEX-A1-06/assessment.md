# LEX-A1-06 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-a1-6dc5c9-a"></a>
- **Item 1:** Lista pede um pacote de arroz. Escreva com one bag of…

<a id="lx-a1-eda3b4-a"></a>
- **Item 2:** Há dois ovos em casa e são necessários cinco. Escreva o que falta em inglês; pode fazer conta no papel.

<a id="lx-a1-20e662-a"></a>
- **Item 3:** A lista diz “We don’t have any milk”. Qual produto falta? Escreva uma frase para pedi-lo.

<a id="lx-a1-a3fc43-a"></a>
- **Item 4:** Uma frase diz “The meal is free”. Isso afirma que a carne é gratuita ou que a refeição é gratuita?

<a id="lx-a1-822643-a"></a>
- **Item 5:** Etiqueta “Price: 7 credits”. Informe o preço em inglês e não a quantidade do produto.

<a id="lx-a1-f692ea-a"></a>
- **Item 6:** Nesta loja fictícia, o cartaz classifica ingressos de 1–2 créditos como cheap. O ingresso custa 2. Escreva a classificação.

<a id="lx-a1-1c4c84-a"></a>
- **Item 7:** A personagem chama de expensive opções acima de 20 créditos. Uma sala custa 25. Escreva uma frase preservando essa avaliação.


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
