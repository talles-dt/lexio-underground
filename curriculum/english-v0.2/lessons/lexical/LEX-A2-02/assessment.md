# LEX-A2-02 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-a2-4b2a2d-a"></a>
- **Item 1:** Pedido enviado, reserva não aceita. Podemos escrever “The room is booked” como fato confirmado?

<a id="lx-a2-bb639c-a"></a>
- **Item 2:** Sala livre das15h às17h; pedido para14h. Responda usando available.

<a id="lx-a2-2532d7-a"></a>
- **Item 3:** Grupo4; sala4lugares. Diga se há enough seats sem inventar folga.

<a id="lx-a2-3da24a-a"></a>
- **Item 4:** Bolsa cabe no armário A, não no B. Complete “The bag ___ in A, but it doesn’t ___ in B”.

<a id="lx-a2-9d803c-a"></a>
- **Item 5:** Oferta diz quiet; outra não informa ruído. Podemos concluir que a segunda é barulhenta?

<a id="lx-a2-021eed-a"></a>
- **Item 6:** Serviço descrito como reliable teve um atraso. A palavra torna o relato impossível?

<a id="lx-a2-60461f-a"></a>
- **Item 7:** Sala25 mais taxa obrigatória3; budget26. A compra fica within the budget?

<a id="lx-a2-61a8d3-a"></a>
- **Item 8:** Recepção diz confirmação enviada; cliente diz não recebeu. Distinga confirm da entrega do e-mail.
