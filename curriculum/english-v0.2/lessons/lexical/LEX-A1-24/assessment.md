# LEX-A1-24 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-a1-a8f08d-a"></a>
- **Item 1:** Relato photo shows snow. Isso prova que neva hoje onde o aluno está?

<a id="lx-a1-3782f1-a"></a>
- **Item 2:** Previsão foggy tomorrow. É observação de hoje?

<a id="lx-a1-c926cd-a"></a>
- **Item 3:** Relato cool, not cold. Preserve contraste em português.

<a id="lx-a1-c49d9a-a"></a>
- **Item 4:** Pedido one umbrella; recebido two. Quantidade correta?

<a id="lx-a1-0b60c9-a"></a>
- **Item 5:** Mesma data em dois lugares. Podemos inferir mesma season/clima?

<a id="lx-a1-ce285f-a"></a>
- **Item 6:** Uma placa 20°C e outra 20°F. São temperaturas iguais só porque número é 20?


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
