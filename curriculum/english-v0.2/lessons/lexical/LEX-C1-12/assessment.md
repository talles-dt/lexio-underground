# LEX-C1-12 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-c1-09d436-a"></a>
- **Item 1:** Totais acumulados quarta 40, quinta 55. Quantos foram acrescentados e como relatar?

<a id="lx-c1-71d0da-a"></a>
- **Item 2:** Reformule promessa vaga em pedido cortês de data para organizar agenda.

<a id="lx-c1-3c24a4-a"></a>
- **Item 3:** Mudança provisória para sala 2 sem data de retorno. Redija aviso fiel.

<a id="lx-c1-4bd82a-a"></a>
- **Item 4:** Três ajustes distribuídos no semestre; redija sem sugerir alteração diária.

<a id="lx-c1-d67bc4-a"></a>
- **Item 5:** Houve consulta, depois mudança; causa não documentada. Redija com limite.

<a id="lx-c1-5c578f-a"></a>
- **Item 6:** Plano original previa dez dias; depois descobriram tarefa adicional de cinco. Reavalie sem atribuir conhecimento retroativo.


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
