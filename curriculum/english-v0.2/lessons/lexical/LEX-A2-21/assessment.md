# LEX-A2-21 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-a2-be327e-a"></a>
- **Item 1:** Você disse cheaper mas queria lower total cost, não parcela menor. Reformule.

<a id="lx-a2-13949c-a"></a>
- **Item 2:** Colega pede número que você não lembra. Use expressão e não invente número.

<a id="lx-a2-bb375e-a"></a>
- **Item 3:** Uma instrução foi repetida, mas sentido continua obscuro. Faça pedido adequado.

<a id="lx-a2-000bae-a"></a>
- **Item 4:** Mensagem two tickets each; peça confirmar cada pessoa recebe dois.

<a id="lx-a2-0377c2-a"></a>
- **Item 5:** Informação de horário não verificada. Responda sem inventar.

<a id="lx-a2-a4ecfa-a"></a>
- **Item 6:** Lista necessária ainda aberta; cite pens como exemplo, não lista exaustiva.


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
