# LEX-B1-20 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-b1-e33eef-a"></a>
- **Item 1:** Pessoa quer menos café, não parar. Reformule com cut down on.

<a id="lx-b1-6558ba-a"></a>
- **Item 2:** Tarefa passou de terça para sexta. Descreva com put off sem atribuir motivo.

<a id="lx-b1-19400c-a"></a>
- **Item 3:** Plano previa duas sessões e ambas ocorreram. Descreva cumprimento apenas dessa semana.

<a id="lx-b1-8c0af1-a"></a>
- **Item 4:** Agenda lotada recebe pausa de dez minutos para leitura. Descreva decisão sem exagerar duração.

<a id="lx-b1-b38a57-a"></a>
- **Item 5:** Fonte says trying to balance, resumo says achieved perfect balance. Corrija.

<a id="lx-b1-bc420a-a"></a>
- **Item 6:** Pessoa tentou mas não terminou. É correto I managed to finish?


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
