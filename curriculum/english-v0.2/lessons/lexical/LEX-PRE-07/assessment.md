# LEX-PRE-07 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-pre-a1-a7a07c-a"></a>
- **Item 1:** Uma mensagem recebida agora diz “Room 4 today”. Explique quando vale a sala 4.

<a id="lx-pre-a1-69d072-a"></a>
- **Item 2:** Convite: Friday 9h; correção escrita: Monday 9h. Qual é o dia final em português?

<a id="lx-pre-a1-3c42a3-a"></a>
- **Item 3:** Agenda: Monday 10h; Friday 11h. Qual horário está na sexta-feira?

<a id="lx-pre-a1-07dcf9-a"></a>
- **Item 4:** Convite: Friday, at ten in the morning. Registre o horário em dígitos.

<a id="lx-pre-a1-c7c770-a"></a>
- **Item 5:** Aviso: Code 501; Room 6. Qual é a sala? Use room na resposta.

<a id="lx-pre-a1-7292bc-a"></a>
- **Item 6:** Ficha: Room 4; Code 902. Informe o código sem trocar pela sala.


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
