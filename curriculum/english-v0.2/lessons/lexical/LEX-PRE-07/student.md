# LEX-PRE-07 — Confirmar o encontro certo

Após [FND-06](../../foundation/FND-06/student.md). Material autoral; não revisado independentemente nem pilotado.

## Percurso

Primeiro estude sentidos e exemplos; depois faça a prática antes de consultar respostas. Faça a situação em dupla ou registre ensaio individual. No início do encontro seguinte, antes de reler, abra [retomada](review.md). Depois da correção e em uma sessão separada, faça a [avaliação](assessment.md), sem consultar previamente suas respostas. Datas e duração são registradas, não presumidas.

## Sentidos, formas e prática

<a id="lx-pre-a1-a7a07c-i"></a>
### today

**Sentido:** hoje. **Padrão:** today + oração. **Exemplo:** English today?

bloco inicial apoiado

<a id="lx-pre-a1-a7a07c-p"></a>
**Prática:** No aviso “English today”, today indica hoje ou amanhã?

<a id="lx-pre-a1-69d072-i"></a>
### Monday

**Sentido:** segunda-feira. **Padrão:** on Monday. **Exemplo:** We meet on Monday.

dias com inicial maiúscula

<a id="lx-pre-a1-69d072-p"></a>
**Prática:** No cartão “Monday, room 2”, qual é o dia em português?

<a id="lx-pre-a1-3c42a3-i"></a>
### Friday

**Sentido:** sexta-feira. **Padrão:** on Friday. **Exemplo:** The class is on Friday.

completar semana no banco de apoio

<a id="lx-pre-a1-3c42a3-p"></a>
**Prática:** No cartão “Friday, room 2”, qual é o dia em português?

<a id="lx-pre-a1-07dcf9-i"></a>
### at ten

**Sentido:** às dez. **Padrão:** at + hora. **Exemplo:** At ten, please.

confirmar manhã ou noite

<a id="lx-pre-a1-07dcf9-p"></a>
**Prática:** Em “Monday, at ten”, ten indica hora ou número da sala?

<a id="lx-pre-a1-c7c770-i"></a>
### room

**Sentido:** sala. **Padrão:** room + número. **Exemplo:** Room three.

room também pode significar espaço disponível

<a id="lx-pre-a1-c7c770-p"></a>
**Prática:** Em “Room 7”, room significa sala ou preço?

<a id="lx-pre-a1-7292bc-i"></a>
### code

**Sentido:** código. **Padrão:** code + dígitos. **Exemplo:** My code is three zero five.

usar dados fictícios

<a id="lx-pre-a1-7292bc-p"></a>
**Prática:** Ficha: Name Kim; Code 207. Qual é o código?

<a id="uso"></a>
## Usar para realizar uma tarefa

Neste cenário fictício, hoje é Monday. Cartão A: English today, at ten in the morning, Room 2, Code 615. Cartão B: English on Friday, at ten in the morning, Room 8, Code 370. Cada pessoa passa sua informação ao parceiro. O parceiro registra se é hoje ou sexta-feira, hora, sala e código. Depois explica em português por que dois encontros at ten não são necessariamente o mesmo encontro.

**Critério:** o destinatário precisa recuperar os dados finais indicados no [retorno](feedback.md). Marque cada palavra como usada com apoio, usada sem modelo, reconhecida somente ou não observada. Sem parceiro, há ensaio, não interação observada.

## Phonos, Pulse, Palácio, Shadow e Syntaxis

Separar DAY / TIME / ROOM / CODE por pausas. Confirmar cada campo que o interlocutor não recuperou.

No Pulse, use a retomada com dados diferentes. No Palácio, guarde uma expressão com situação própria; no Shadow, troque papéis e confirme o que o ouvinte entendeu. Consulte as microaulas Syntaxis da unidade de fundamentos se uma forma bloquear o sentido.
