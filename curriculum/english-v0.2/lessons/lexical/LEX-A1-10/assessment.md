# LEX-A1-10 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-a1-333470-a"></a>
- **Item 1:** Peça camisa azul retomando blue: The…, please.

<a id="lx-a1-462f12-a"></a>
- **Item 2:** Você quer calça preta. Use The black trousers, please.

<a id="lx-a1-58660e-a"></a>
- **Item 3:** Você aponta sapatos brancos. Complete These ___ are white.

<a id="lx-a1-450451-a"></a>
- **Item 4:** Cartão de compra diz tamanho M, preço 15. Responda What size? sem confundir valor.

<a id="lx-a1-1044a8-a"></a>
- **Item 5:** Peça experimentar sapatos usando them, com apoio.

<a id="lx-a1-a9bad8-a"></a>
- **Item 6:** Pergunte possibilidade de pagar com cartão.


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
