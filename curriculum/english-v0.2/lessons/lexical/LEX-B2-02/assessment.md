# LEX-B2-02 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-b2-d253eb-a"></a>
- **Item 1:** Peça confirmar se revisão de imagens faz parte do trabalho.

<a id="lx-b2-3641e2-a"></a>
- **Item 2:** Explique a público geral o deliverable acordado: guia de duas páginas.

<a id="lx-b2-0667c8-a"></a>
- **Item 3:** Versão longa explica mais, curta é mais rápida de ler. Compare sem declarar vencedora universal.

<a id="lx-b2-e79572-a"></a>
- **Item 4:** Documentos enviados mas destinatário ainda não aceitou responsabilidade. Descreva limite da transferência.

<a id="lx-b2-cb2a35-a"></a>
- **Item 5:** Ofereça sala se equipamento for conferido antes. Não declare conferência feita.


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
