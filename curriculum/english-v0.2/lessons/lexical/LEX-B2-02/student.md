# LEX-B2-02 — Combinar entrega e transferência de responsabilidade

Após [B2-01](../../b2/B2-01/student.md). Material autoral; não revisado independentemente nem pilotado.

## Percurso

Primeiro estude sentidos e exemplos; depois faça a prática antes de consultar respostas. Faça a situação em dupla ou registre ensaio individual. No início do encontro seguinte, antes de reler, abra [retomada](review.md). Depois da correção e em uma sessão separada, faça a [avaliação](assessment.md), sem consultar previamente suas respostas. Datas e duração são registradas, não presumidas.

## Sentidos, formas e prática

<a id="lx-b2-d253eb-i"></a>
### scope

**Sentido:** escopo. **Padrão:** within/outside the scope. **Exemplo:** The translation is outside the scope.

não prazo

<a id="lx-b2-d253eb-p"></a>
**Prática:** Tradução não faz parte do serviço acordado. Use scope.

<a id="lx-b2-3641e2-i"></a>
### deliverable

**Sentido:** entrega definida. **Padrão:** a project deliverable. **Exemplo:** The summary is the first deliverable.

jargão de trabalho; explicar a público geral

<a id="lx-b2-3641e2-p"></a>
**Prática:** Projeto define resumo escrito como entrega. Nomeie.

<a id="lx-b2-0667c8-i"></a>
### trade-off

**Sentido:** compromisso entre ganhos e perdas. **Padrão:** a trade-off between A and B. **Exemplo:** There is a trade-off between speed and detail.

não implica escolha binária inevitável

<a id="lx-b2-0667c8-p"></a>
**Prática:** Mais detalhes exigem mais tempo neste cenário. Nomeie relação.

<a id="lx-b2-e79572-i"></a>
### hand over

**Sentido:** entregar responsabilidade. **Padrão:** hand something over. **Exemplo:** We’ll hand the project over on Friday.

confirmar destinatário e estado da entrega

<a id="lx-b2-e79572-p"></a>
**Prática:** Diga entregar responsabilidade do projeto a Lee sexta.

<a id="lx-b2-cb2a35-i"></a>
### provided that

**Sentido:** desde que. **Padrão:** provided that + condição. **Exemplo:** We can deliver provided that the draft is approved.

não eliminar condição no resumo

<a id="lx-b2-cb2a35-p"></a>
**Prática:** Entrega ocorre se rascunho for aprovado até terça. Use provided that.

<a id="uso"></a>
## Usar para realizar uma tarefa

A cliente quer guia de duas páginas até sexta. Escopo inclui redação e revisão, exclui tradução. B equipe pode entregar sexta desde que aprove rascunho terça. Mais exemplos exigem quatro páginas e revisão adicional; não há prazo dessa alternativa confirmado. Lee assumirá manutenção após reunião de transferência, ainda não marcada. Negociem sem transformar envio de arquivo em transferência já aceita.

**Critério:** o destinatário precisa recuperar os dados finais indicados no [retorno](feedback.md). Marque cada palavra como usada com apoio, usada sem modelo, reconhecida somente ou não observada. Sem parceiro, há ensaio, não interação observada.

## Phonos, Pulse, Palácio, Shadow e Syntaxis

Marque pausa antes de provided that; ouvinte repete entrega e condição. Pratique hand it OVER to LEE com objeto pronominal no meio.

No Pulse, use a retomada com dados diferentes. No Palácio, guarde uma expressão com situação própria; no Shadow, troque papéis e confirme o que o ouvinte entendeu. Consulte as microaulas Syntaxis da unidade de fundamentos se uma forma bloquear o sentido.
