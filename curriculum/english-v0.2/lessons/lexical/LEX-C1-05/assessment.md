# LEX-C1-05 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-c1-27e186-a"></a>
- **Item 1:** Cena mostra fala cordial e gesto de afastamento. Proponha leitura marcada.

<a id="lx-c1-b162e5-a"></a>
- **Item 2:** Crie formulação moderada para situação ficcional de sala muito cheia e explique.

<a id="lx-c1-3d4f1e-a"></a>
- **Item 3:** Texto só informa porta fechada. Evite inferir hostilidade automaticamente.

<a id="lx-c1-b2d921-a"></a>
- **Item 4:** Personagem menciona malas prontas, destino desconhecido. Descreva sugestão.

<a id="lx-c1-f417af-a"></a>
- **Item 5:** Ela apoia proposta, teme seus efeitos. Relate sem diagnóstico.

<a id="lx-c1-07e5de-a"></a>
- **Item 6:** Texto lhe lembra casa, outro leitor não. Descreva experiência situada.


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
