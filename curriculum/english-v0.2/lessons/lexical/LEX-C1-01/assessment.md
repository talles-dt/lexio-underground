# LEX-C1-01 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-c1-645777-a"></a>
- **Item 1:** Reescreva “Everyone benefited”: só oito respondentes relataram benefício.

<a id="lx-c1-f7e3f6-a"></a>
- **Item 2:** Admita limitação de amostra e explique valor exploratório.

<a id="lx-c1-de16b5-a"></a>
- **Item 3:** Relato coincide com bilhete datado, mas motivo segue desconhecido. Delimite.

<a id="lx-c1-8c8b7d-a"></a>
- **Item 4:** Um relatório soma inscritos, outro presentes. Explique necessidade.

<a id="lx-c1-f0b474-a"></a>
- **Item 5:** Sala e equipamento prontos, horário depende de uma resposta. Resuma o entrave atual.

<a id="lx-c1-930e9d-a"></a>
- **Item 6:** Relatório útil apenas para quem respondeu. Formule limite.

<a id="lx-c1-cd9d51-a"></a>
- **Item 7:** Atraso pode decorrer de transporte, mas faltam registros. Relate.


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
