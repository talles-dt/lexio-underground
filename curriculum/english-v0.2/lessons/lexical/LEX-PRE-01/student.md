# LEX-PRE-01 — Receber e apresentar pessoas

Após [FND-01](../../foundation/FND-01/student.md). Material autoral; não revisado independentemente nem pilotado.

## Percurso

Primeiro estude sentidos e exemplos; depois faça a prática antes de consultar respostas. Faça a situação em dupla ou registre ensaio individual. No início do encontro seguinte, antes de reler, abra [retomada](review.md). Depois da correção e em uma sessão separada, faça a [avaliação](assessment.md), sem consultar previamente suas respostas. Datas e duração são registradas, não presumidas.

## Sentidos, formas e prática

<a id="lx-pre-a1-d56634-i"></a>
### hello

**Sentido:** cumprimento. **Padrão:** hello + nome. **Exemplo:** Hello, Jo.

hi é alternativa informal; não significa despedida

<a id="lx-pre-a1-d56634-p"></a>
**Prática:** Você encontra Jo pela primeira vez. Escolha hello/goodbye para iniciar.

<a id="lx-pre-a1-6c75b6-i"></a>
### name

**Sentido:** nome de pessoa. **Padrão:** my name is + nome. **Exemplo:** My name is Lia.

nome fictício é suficiente

<a id="lx-pre-a1-6c75b6-p"></a>
**Prática:** No cartão “Name: Lee”, Lee é um nome ou uma sala?

<a id="lx-pre-a1-e881d0-i"></a>
### first name

**Sentido:** nome próprio. **Padrão:** first name + is. **Exemplo:** My first name is Ana.

não presumir estrutura universal de nomes

<a id="lx-pre-a1-e881d0-p"></a>
**Prática:** Cartão: First name: Ana; Last name: Silva. Qual é o nome próprio?

<a id="lx-pre-a1-4c0a74-i"></a>
### last name

**Sentido:** sobrenome. **Padrão:** last name + is. **Exemplo:** My last name is Silva.

confirmar como a pessoa organiza seu nome

<a id="lx-pre-a1-4c0a74-p"></a>
**Prática:** No cartão Ana Silva, “Last name: Silva” indica qual dado?

<a id="lx-pre-a1-4271df-i"></a>
### nice to meet you

**Sentido:** acolher apresentação. **Padrão:** nice to meet you. **Exemplo:** Nice to meet you, Lee.

não substitui resposta à pergunta de nome

<a id="lx-pre-a1-4271df-p"></a>
**Prática:** Alguém diz “I’m Jo.” Escolha nice to meet you/room two para acolher a apresentação.

<a id="lx-pre-a1-3a6639-i"></a>
### friend

**Sentido:** amigo ou amiga. **Padrão:** my friend. **Exemplo:** This is my friend Jo.

não informa gênero por si só

<a id="lx-pre-a1-3a6639-p"></a>
**Prática:** “This is my friend Jo” apresenta amigo/amiga ou professor obrigatoriamente?

<a id="uso"></a>
## Usar para realizar uma tarefa

A organiza a recepção. B tem cartão: First name: Rui; Last name: Melo; friend: Eva. A cumprimenta B, pergunta o nome com What’s your name? e confirma os campos com First name? / Last name?. B responde e apresenta Eva com This is my friend Eva. A acolhe a apresentação. Troquem papéis com First name: Lia; Last name: Reis; friend: Kim.

**Critério:** o destinatário precisa recuperar os dados finais indicados no [retorno](feedback.md). Marque cada palavra como usada com apoio, usada sem modelo, reconhecida somente ou não observada. Sem parceiro, há ensaio, não interação observada.

## Phonos, Pulse, Palácio, Shadow e Syntaxis

Ouça e ensaie HELlo e NAME com apoio de pessoa ou voz do dispositivo. O parceiro deve recuperar o nome; não avalie imitação de sotaque.

No Pulse, use a retomada com dados diferentes. No Palácio, guarde uma expressão com situação própria; no Shadow, troque papéis e confirme o que o ouvinte entendeu. Consulte as microaulas Syntaxis da unidade de fundamentos se uma forma bloquear o sentido.
