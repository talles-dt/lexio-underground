# LEX-PRE-01 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-pre-a1-d56634-a"></a>
- **Item 1:** Receba Noa com um cumprimento, sem se despedir.

<a id="lx-pre-a1-6c75b6-a"></a>
- **Item 2:** O campo diz “Name: Eva”. Diga qual informação deve entrar ali: horário, nome ou preço.

<a id="lx-pre-a1-e881d0-a"></a>
- **Item 3:** Cartão: First name: Mia; Last name: Lima. Responda “What’s your first name?” como essa pessoa.

<a id="lx-pre-a1-4c0a74-a"></a>
- **Item 4:** Cartão: First name: Mia; Last name: Lima. Responda “What’s your last name?” como essa pessoa.

<a id="lx-pre-a1-4271df-a"></a>
- **Item 5:** Depois de ouvir “My name is Sol”, acolha a apresentação com a expressão estudada.

<a id="lx-pre-a1-3a6639-a"></a>
- **Item 6:** Você apresenta Alex como amigo/amiga. Complete “This is my ___ Alex”.


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
