# LEX-PRE-01 — retomada no encontro seguinte

[Ensino](student.md) · [Retorno](feedback.md). Faça antes de reler o ensino; anote o apoio. Se precisar, consulte e marque tentativa com consulta. Não confundir correção imediata com retomada posterior.

<a id="lx-pre-a1-d56634-r"></a>
- **Item 1:** No encontro seguinte, cumprimente uma pessoa chamada Kim.

<a id="lx-pre-a1-6c75b6-r"></a>
- **Item 2:** Em outro dia, preencha “My name is ___” com um nome fictício diferente.

<a id="lx-pre-a1-e881d0-r"></a>
- **Item 3:** Novo cartão: First name: Ben; Last name: Costa. Copie apenas o nome próprio.

<a id="lx-pre-a1-4c0a74-r"></a>
- **Item 4:** Novo cartão: First name: Ben; Last name: Costa. Copie apenas o sobrenome.

<a id="lx-pre-a1-4271df-r"></a>
- **Item 5:** Em outro dia, receba “Hello. I’m Alex.” e acolha a apresentação.

<a id="lx-pre-a1-3a6639-r"></a>
- **Item 6:** Em outro dia, apresente uma pessoa fictícia chamada Sol como amiga.
