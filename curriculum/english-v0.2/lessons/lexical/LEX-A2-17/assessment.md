# LEX-A2-17 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-a2-b04953-a"></a>
- **Item 1:** Você vê água pingando mas não sabe a origem. Escreva mensagem com leak e cause unknown como apoio.

<a id="lx-a2-76dfb0-a"></a>
- **Item 2:** Sala fria; controle liga mas não aquece. Relate heating sem diagnosticar peça.

<a id="lx-a2-5aa7bd-a"></a>
- **Item 3:** Cartão Ana rents the flat to Lee. Quem é landlord?

<a id="lx-a2-52a214-a"></a>
- **Item 4:** Cartão Rui owns the flat; Jo rents it from Rui. Escreva quem é tenant.

<a id="lx-a2-102a40-a"></a>
- **Item 5:** Contrato começa sexta, mudança real sábado. Relate move in com o dia real.

<a id="lx-a2-755252-a"></a>
- **Item 6:** Pessoa saiu para trabalhar e voltou. Isso basta para dizer moved out?
