# LEX-A1-23 — avaliação lexical

[Guia de aplicação](teacher.md). Material reservado para uma sessão posterior à retomada. Instruções em português e apoio de formato são permitidos; não usar o gabarito. Registre por item produção, reconhecimento ou escuta conforme a tarefa; reconhecer uma palavra não demonstra uso produtivo.

<a id="lx-a1-206b97-a"></a>
- **Item 1:** Loja cash only. Cartão é aceito segundo a placa?

<a id="lx-a1-8fa6ac-a"></a>
- **Item 2:** Placa cards accepted. Segundo placa, cartão é aceito?

<a id="lx-a1-9aaffe-a"></a>
- **Item 3:** Preço 4, paga 10, conta fornecida 10−4=6. Diga troco.

<a id="lx-a1-3d52b5-a"></a>
- **Item 4:** Aviso pay at checkout; onde concluir pagamento fictício?

<a id="lx-a1-f3add5-a"></a>
- **Item 5:** Pessoa diz I bought a ticket; bought = passado dado. Comprou ou só quis comprar?

<a id="lx-a1-a0de58-a"></a>
- **Item 6:** Cartão They don't sell tickets. É correto procurar ingresso ali com base nessa informação?


Após terminar, confira [respostas](feedback.md) e preserve a primeira tentativa. Tarefas realizadas sem áudio/interlocutor ficam parciais quando esses recursos forem necessários.
